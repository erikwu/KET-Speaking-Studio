# KET Speaking · 本地朗读练习

TypeScript 本地网页读取 Markdown 中的 Part 1 / Phase 1、Part 1 / Phase 2 和 Part 2 台词，并通过 Apple MLX 本地生成逐句语音。服务只监听 `127.0.0.1`；Markdown、生成音频和语气指令都保留在本机。

## 新机器一键安装

适用于 Apple Silicon Mac。双击项目根目录的 `install.command`，脚本会检查并准备 Homebrew、Node.js 22、Python 3.13、FFmpeg 和项目 `.venv`，安装 MLX-Audio、mlx-whisper、mlx-lm 与支持 Qwen Image 2.1 的 mflux，下载并校验语音、图片、模拟考转写和评分模型，随后启动服务并打开 <http://127.0.0.1:8788>。

TTS 与图片模型加上模拟考模型约需 33 GiB 磁盘空间；首次安装建议至少保留 40 GiB 可用空间和稳定网络。模拟考所需权重约 3.9 GB，安装器会按约 5 GiB 预留空间。若 macOS 尚未安装 Command Line Tools，脚本会打开 Apple 的安装窗口；完成后回到终端按回车继续。Homebrew 安装时可能要求输入本机管理员密码。模型下载支持断点续传，已校验完整的模型会跳过。

安装完成后，服务会在打开的终端窗口持续运行；按 Control-C 停止。再次双击 `install.command` 可复用已安装环境和模型，并启动页面。

考试模型分别为 [`mlx-community/whisper-large-v3-turbo`](https://huggingface.co/mlx-community/whisper-large-v3-turbo)（约 1.6 GB）和 [`mlx-community/Qwen3-4B-4bit`](https://huggingface.co/mlx-community/Qwen3-4B-4bit)（约 2.3 GB）。前者使用 MIT 许可，后者使用 Apache-2.0 许可；安装前请查看各 Hugging Face 仓库当前提供的模型卡和许可文件。安装器不替用户接受模型许可条款。

图片模型 `JoyFusionAI/Qwen-Image-2.1-MLX-4bit` 是 Qwen Image 2.1 衍生模型，采用 Qwen Research License；商业用途需要另行取得许可。脚本只下载模型，不会替用户接受任何模型许可条款。

首次朗读会加载语音模型。之后服务会在后台保留模型，逐句合成时无需反复重新加载。音频保存在 `outputs/speech-practice/`。

## 模拟考

读取包含 Part 1 / Phase 1、Part 1 / Phase 2 和 Part 2 的材料后，点击“开始模拟考”。Part 1 会播放问题但隐藏英文题面；学生录音回答后，本机 Whisper 识别英文，再由本机 Qwen3 按切题度、信息完整度、语法和词汇各 0–5 分评分，不评价口音或发音。Part 2 按情景随机选择学生或电脑先开，电脑台词播放完成后才进入学生的中文提示。

点击“查看参考答案/台词”会累计提示次数。结束页提供各阶段逐题转写、分项得分、阶段均分、未完成题数和提示次数。评分失败时保留已有转写以便只重试评分；识别失败则可重新录音。录音最多 120 秒，由页面发送到同一台 Mac 的 `127.0.0.1` 服务处理；录音临时文件在处理后删除，录音、转写、评分和提示统计仅存在于本次页面内存，不写入 Markdown、离线资源包或持久化存储。刷新页面、关闭页面或切换材料会清除本场内容。

模拟考要求完整安装 Whisper、Qwen3 评分模型、`mlx-whisper`、`mlx-lm` 和 FFmpeg。缺少任一组件时，入口会说明缺项并禁用开考；本地 TTS、已有离线语音和已缓存图片仍按各自能力继续使用。无模型 Mac 可按上文导入离线资源包进行普通跟读，但不能使用模拟考。

## 离线语音缓存

读取练习材料后，可在“离线语音”面板生成整份材料的语音缓存。首次生成固定使用应用的默认音色和语气标签；如果本机已有离线包，可选择按当前标签重新生成。重新生成期间，练习列表和标签仍可继续使用，生成任务会逐句在后台运行，前台点击朗读会优先于后续缓存句子。生成全部成功后，新包才会替换旧包；失败时旧的完整包会保留。

“播放方式”默认为实时合成。选择“离线优先”后，每句先读取与当前材料匹配的本地 WAV；如果该句没有缓存，应用会提示并按当前标签实时合成。已缓存语音使用生成时保存的音色，不会随标签改动；要更新它们，请手动重新生成并替换。

## 跨设备离线资源包

当前材料的完整离线语音通过完整性校验后，页面会提供“下载离线资源包”。`.ketpack.zip` 内有 Markdown 原文、完整语音包中的每句 WAV，以及当前材料已经生成的 Part 2 PNG 配图；未生成的配图不会补生成。模型文件、Python 环境、无关材料和其他输出不会打包。

另一台 Mac 在 8788 页面可以先导入资源包，不需要先读取 Markdown 路径。上传验证成功后，包内 Markdown 会成为当前材料，页面直接载入问答、离线语音状态和配图。每次只保留一个活动离线语音包；有效导入会替换它，包版本、文件校验或问答映射验证失败时则保留原来的材料和语音包。其他材料已缓存的情景图片不受影响。

### 无模型机器启动 8788

第二台 Mac 需要项目文件、Node.js 22 或更新版本，以及 macOS 自带的 `zip` 和 `unzip`。在项目根目录运行：

```sh
npm run start:tts
```

然后打开 <http://127.0.0.1:8788> 并导入 `.ketpack.zip`。这台机器不要运行 `install.command`，因为该脚本会安装推理环境并下载模型。没有语音模型或 MLX-Audio 时，页面自动切换到“仅播放离线语音”，实时合成和语音缓存生成会禁用；包里缺少的句子会显示不可用，不会回退到实时合成。没有图片模型或 mflux 时，已打包配图仍可查看，配图生成按钮会禁用。

每次只保留一份完整离线包，保存于 `outputs/speech-practice/offline-audio/`。未完成的数据暂存在旁边的 staging 目录，不会用于播放。播放偏好保存在当前浏览器的本机存储中；语音和材料不会发送到网络服务。全材料缓存由用户点击后才会开始，应用初始化和实现检查都不会自动生成整份材料。

## 支持的 Markdown 结构

段落标题按 `Part 1 / Phase 1`、`Part 1 / Phase 2`、`Part 2` 识别。Part 1 读取 `**Q: ...**` 和 `**A: ...**`；Part 2 读取 `**A: ...**`、`**B: ...**` 对话行以及编号的 `情境：` 标题。括号中的中文翻译显示在台词下方，不会合成。问号结尾的 Part 2 台词使用问句语气，其余台词使用回答语气。

页面提供基础音色、问句语气和回答语气的多选标签。所选标签保存在浏览器本机，合成时会组合成自然语言指令传给 Qwen3-TTS VoiceDesign 模型。可在输入框中填写 `.md` 文件的绝对路径。

Part 2 的每个情景都提供“生成两张配图”按钮，使用项目中的本地 Qwen Image MLX 模型。提示词会结合情景标题和 A/B 完整对话，画出说话双方讨论的活动、地点和物品，供看图练习；两张配图呈现不同瞬间。图片会按练习文件和对话内容保存在 `outputs/speech-practice/scenario-images/`，重新读取同一份材料时会继续显示；再次生成会替换该情景的图片。该功能需要项目 `.venv` 中的 `mflux-generate-qwen-2.1` 命令和完整的 Qwen Image 模型。
