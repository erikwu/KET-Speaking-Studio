# KET Speaking Studio

**听一句，练一句，让孩子更愿意开口说英语。**

中文 | [English](README.en.md)

这是我在假期用 AI 辅助开发的一个业余项目，最初是为了陪家里的小朋友练习英文、准备 KET（Cambridge A2 Key）。它在 Mac 上运行，用浏览器就能逐句跟读、练习对话、参加模拟考，并获得本地 AI 的转写和反馈。

我也加入了一些轻量的游戏化设计：练习进度、逐题得分、满分音效，希望让“再试一次”更有吸引力。欢迎家长、学习者和喜欢折腾 AI 的朋友一起试用、提建议。

[快速上手](#快速上手最小安装) · [获取练习材料](#练习材料从哪里来) · [日常使用](#如何开始练习) · [常见问题](#常见问题)

## 你可以用它做什么

- **逐句跟读**：播放问题和答案，按自己的节奏反复练习；材料中的中文翻译会显示在英文下方。
- **情景对话**：按 Part 1 / Phase 1、Part 1 / Phase 2 和 Part 2 整理材料，保留对话角色、上下文和已有配图。
- **模拟考**：听题、录音回答，查看转写，以及切题度、信息完整度、语法和词汇四项反馈。
- **复习与鼓励**：查看进度、提示次数和逐题成绩，重新作答练习，开启或关闭满分音效，保存成绩为 PDF。
- **本机使用**：语音识别和评分在本机运行。完成安装并准备好资源后，可以离线练习，无需云端 AI API 密钥。

AI 分数用于练习参考，不是 Cambridge 官方评分，也不评发音或口音。当前界面和安装提示主要为中文；英文指南会标注对应的按钮名称。

## 选择适合你的安装方式

需要 **Apple Silicon Mac（M 系列芯片）**。安装器会准备所需运行环境；首次安装和检查更新需要联网。

| | 最小安装：已有资源包时推荐 | 完整安装：制作自己的语音和配图 |
| --- | --- | --- |
| 逐句播放、查看配图 | 使用导入资源包里的音频和图片 | 可在本机生成，也可导入 |
| 模拟考、录音转写、AI 评分 | 支持 | 支持 |
| 自定义音色、实时语音、生成配图 | 不支持生成；已有资源仍可使用 | 支持 |
| 模型下载量 | 约 3.9 GB | 约 33 GiB |
| 建议预留磁盘空间 | 约 10 GiB | 至少 40 GiB |

上面的数字是下载量和磁盘空间，**不是内存要求**；模型运行速度和内存占用因设备与任务而异。最小安装包含模拟考模型，并不等于“完全不装模型”。只想播放已有语音时，见下方[无模型播放方式](#只播放已有语音不安装-ai-模型)。

## 快速上手：最小安装

### 1. 准备项目和资源包

1. 在[项目首页](https://github.com/erikwu/KET-Speaking-Studio)点击 **Code → Download ZIP**。
2. 解压到一个固定文件夹。
3. 下载[默认练习资源包](https://drive.google.com/file/d/1SbQ-aulyipVFaVSg_zly7SvpYDHMWtJb/view?usp=drive_link)（`.ketpack.zip`），或准备自己的资源包。资源包包含练习材料和预生成语音，与项目代码分开下载；模型由安装器下载。

### 2. 运行安装器

双击项目里的 [`install.command`](install.command)，输入 **`2`** 并回车，选择 **最小安装**。直接回车会选择默认的完整安装。

按终端提示完成安装：如果弹出 Apple Command Line Tools 安装窗口，安装结束后回到终端按回车；安装 Homebrew 时可能需要输入本机管理员密码。第一次需要下载依赖和模型，请留出时间，下载中断后可重新运行。

安装完成后会自动打开 [http://127.0.0.1:8788](http://127.0.0.1:8788)。使用期间保持终端窗口运行。

### 3. 导入并开始练习

1. 点击 **导入资源包**，选择 `.ketpack.zip`，无需解压，也不必填写原电脑的文件路径。
2. 材料载入后，选择一个练习部分，点击 **朗读**，听一句、跟读一句。
3. 准备好后点击 **开始模拟考**，允许浏览器使用麦克风，再按页面提示回答。

最小安装默认使用 **离线优先**；“读取文件与离线语音”和“设置声音与语气”默认折叠。修改音色标签不会改变已经生成的音频。

## 练习材料从哪里来

### 已有资源包

先试用[默认练习资源包（Google Drive）](https://drive.google.com/file/d/1SbQ-aulyipVFaVSg_zly7SvpYDHMWtJb/view?usp=drive_link)。也可以在“选择练习材料”面板点击 **下载默认材料**，下载后点击 **导入资源包**。鼠标停在下载链接上可查看操作提示。

还可以使用另一台完整安装的 Mac 导出的资源包，或请使用该工具的家人、老师分享。包内包含 Markdown 问答、完整语音，以及已生成的配图；不包含 AI 模型。

每次导入成功会替换当前活动语音包；校验失败则保留原资源。需要保留多套材料时，请保存各自的资源包，使用时切换导入。

### 制作自己的资源包

可以让 AI 按下方格式生成新的 Markdown 问答，再自行检查内容是否适合孩子的水平。如需协助，欢迎通过面板里的 **问号提示图标** 在 [LinkedIn](https://www.linkedin.com/in/erik-wu-pmp-csm-15226412/) 找我；鼠标悬停查看提示，点击图标打开 LinkedIn。AI 生成的文字仍需生成语音，才能制作可在最小安装中播放的资源包。

在一台选择 **`1` — 完整安装** 的 Mac 上：

1. 准备 `.md` 格式的问答文件，展开 **读取文件与离线语音**，填写本机文件的完整路径，点击 **读取文件**。
2. 点击 **为当前材料生产默认缓存**，等待全部语音生成完成。Part 2 配图可按需生成。
3. 点击 **下载离线资源包**，把导出的 `.ketpack.zip` 复制给最小安装的 Mac。

换电脑后，本机文件路径通常会变化；共享资源包可以避免手动处理路径和音频对应关系。

### 使用 Markdown 问答

以下示例可用于测试读取和逐句练习。保存为 UTF-8 编码的 `.md` 文件，每句台词独占一行：

```markdown
# Part 1 / Phase 1
Q: What is your name?（你叫什么名字？）
A: My name is Alex.（我叫 Alex。）

# Part 1 / Phase 2
Q: What do you like doing after school?（放学后你喜欢做什么？）
A: I like reading books.（我喜欢看书。）

# Part 2
1. Situation: Choosing an activity
A: Shall we play football?（我们踢足球好吗？）
B: I'd like to read a book.（我想读一本书。）
A: OK, let's read together.（好的，我们一起读吧。）
```

支持加粗的 Q/A/B、中文冒号、列表和主题子标题；详细规则见[材料格式说明](speech/README.md#支持的-markdown-结构)。最小安装可读取文字，但仅有 Markdown **不会生成语音**，需要匹配的离线资源包。

模拟考至少需要 Phase 1 的 **8 组问答**、Phase 2 的 **8 组问答**和 Part 2 的 **3 个有效场景**。Part 2 场景前三句须按 A/B/A 排列，并且每句带中文翻译，供考试提示使用。上面的小示例不够开启一场模拟考。

## 如何开始练习

### 跟读：先熟悉，再开口

导入材料 → 切换练习部分 → 点击朗读 → 跟读或自己作答。可以重复听同一句，不必一次完成整份材料。

### 模拟考：听题、回答、复盘

- 每场随机抽取 Phase 1 的 8 题、Phase 2 的 8 题和 Part 2 的 3 个场景，并随机安排顺序。
- Part 1 隐藏英文题面，通过语音出题；Part 2 会随机安排学生或电脑先开口。
- 录音后查看转写和四项评分，每项 0–5 分，总分 20 分。可以查看参考答案，系统会记录提示次数。
- 首次成功评分计入本次成绩；之后的重新作答用于练习，不覆盖首次成绩。
- 结束后查看成绩面板，点击 **保存为 PDF**，在系统打印窗口中选择存储为 PDF。

刷新或关闭页面、切换材料会清除本场结果，离开前请保存。满分音效可以在考试或成绩面板中关闭。

## 下次启动、停止与更新

**再次启动**：双击 `install.command`，仍选择 **`2`**；已完整下载的模型会复用。也可以在项目文件夹的终端运行：

```sh
npm run start:tts
```

然后打开 [http://127.0.0.1:8788](http://127.0.0.1:8788)。**停止服务**：在运行它的终端按 **Control-C**。

**更新应用**：先结束模拟考并保存成绩，再点击右上角 **检查更新 → 更新并重启**。按钮会显示检查、更新、重启和恢复状态，成功后页面自动刷新。左上角显示当前版本号。

更新保留模型、资源包和浏览器设置，最小安装不会变成完整安装。请通过安装器或上面的命令启动，自动重启依赖它们启动的管理进程。

## 常见问题

| 遇到的情况 | 可以这样处理 |
| --- | --- |
| 第一次打开没有题目 | 点击“导入资源包”；首次使用不会自动读取任何人的私人文件路径。 |
| 找不到 Markdown 文件 | 填写这台 Mac 上有效的完整路径；iCloud 文件需先下载到本机。跨设备使用建议导入资源包。 |
| 题目有文字，但没有声音 | 最小安装不会实时生成语音，请导入包含这份材料全部音频的资源包。 |
| 模拟考按钮不可用 | 查看按钮附近提示，确认考试模型安装完成、材料三部分齐全且题量足够。 |
| 无法录音 | 在浏览器和 macOS 隐私设置中允许麦克风，检查输入设备后重试。 |
| 评分失败或转写不理想 | 查看转写，按提示重试评分或重新录音；尽量在安静环境下、靠近麦克风清楚作答。 |
| 浏览器打不开页面 | 确认启动终端仍在运行，并使用它显示的地址；默认端口是 8788。 |
| 安装中断 | 修复终端提示的问题后重跑 `install.command`，仍选原来的配置，完整模型会跳过下载。 |
| 更新被阻止 | 先等待录音、评分、生成或资源包任务结束；若提示代码被修改，备份并处理修改后再更新。 |

### 只播放已有语音，不安装 AI 模型

在已准备好 **Node.js 22+** 和 macOS 自带 `zip` / `unzip` 的 Mac 上，进入项目文件夹运行 `npm run start:tts`，再导入资源包即可。此方式不运行 `install.command`，不会安装模型；可播放已有语音、查看已有配图，**不能进行 AI 模拟考、生成语音或图片**。

## 数据保存在什么地方

- 服务只监听本机 `127.0.0.1`。练习材料、语音识别、评分和配图处理不发送到云端推理服务；安装下载和 GitHub 更新需要网络。
- 模型放在 `models/`，练习资源放在 `outputs/speech-practice/`，浏览器记住最近成功读取的材料和设置。
- 考试录音临时文件在转写处理后删除；本场录音、转写和成绩保留在页面内存，刷新后清除。
- **评分失败的诊断日志会留在本机**：`outputs/speech-practice/exam-diagnostics.jsonl` 可能包含题目、参考答案、学生转写和模型输出，不含录音。提交问题反馈前请先脱敏。
